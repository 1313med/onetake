## Edit structure (A / cutaway intercut)
- Continuous story spine — keep usable speech (≥45s when available).
- **Cutaway plates** must be opaque (`topicBlast`, phone, checklist, brand…). Never transparent overlays like `headlineWall` alone (that caused blank black frames).
- Default **card** mode: face stays dimmed + kinetic topic card. **PIP** for clean variant. Voice continues.
- Entity-first plates: platform → topicBlast, search → checklist, join → phone, FREE → freeBurst, approved → stamp.
- Variant density: A card smash · B PIP · C warm brand/food.
- Optional photo stills: `server/assets/cutaways/<theme>/<key>.jpg|png` staged into Remotion as `coverStill`.

## Motion / graphics
- Snap / slam / bounce presets (not slow fades).
- FREE rays spin + slam word · phone form typing · checklist ticks · stamp rotate-in · doc slide + highlight.

## Audio
